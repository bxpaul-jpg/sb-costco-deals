# SB 코스트코 행사 웹앱

유리카트 유튜브의 코스트코 행사 영상을 정리한 가격표 웹앱입니다. 휴대폰과 PC 브라우저에서 열리고, **접속 코드를 받은 사람만** 볼 수 있습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `docs/index.html` | 웹앱 화면 (GitHub Pages가 `docs/` 폴더를 그대로 공개) |
| `docs/data.enc.json` | 암호화된 행사 데이터와 상품 사진. 코드 없이는 읽을 수 없음 |
| `docs/assets/` | SB 로고 |
| `tools/build.py` | 원본 데이터 + 접속 코드 명단 → `data.enc.json` 생성 |

원본 데이터(`deals.json`, `images.json`)와 접속 코드 명단(`access.json`)은 **저장소에 올리지 않습니다** (`.gitignore`). 공개 저장소라서 올리면 누구나 볼 수 있습니다.

## 접속 코드 관리

1. 비공개 폴더의 `access.json`에 사람(또는 팀)마다 코드를 적습니다. 형식은 `access.example.json` 참고.
2. `python3 tools/build.py --private <비공개 폴더>` 를 실행합니다. (`pip install cryptography` 필요)
3. 바뀐 `docs/data.enc.json`을 커밋·푸시하면 1~2분 뒤 반영됩니다.

코드를 지우고 다시 빌드하면, 그 코드로는 새 데이터를 열 수 없습니다. 이미 받아 간 예전 데이터까지 회수되지는 않습니다.

## 데이터 갱신

매주 월·목 저녁 Claude가 새 영상을 수집해 비공개 `deals.json`에 누적하고, 빌드 후 푸시합니다. 화면은 항상 가장 최근 영상의 행사만 보여주고, 상품마다 지금까지의 행사 횟수와 최저가를 함께 표시합니다.

## 저작권 메모

- 영상 캡처 이미지는 쓰지 않고 가격 정보만 카드로 재구성합니다.
- 상품 사진 저작권은 코스트코 코리아에 있습니다. 접속 코드로 내부 인원에게만 보여주는 참고용입니다.
- 접속 제한은 노출 범위를 줄이는 장치이지 법적 허락을 대신하지는 않습니다. 외부 판매·홍보에 쓰려면 사진 사용 허락을 따로 받거나 직접 찍은 사진으로 바꾸세요.
